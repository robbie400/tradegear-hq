# Carpenter batch: 50 → 75 products

Adds 25 distinct models in five buying guides: nailers; table and track saws; clamps and workholding; planers and joinery; dust extraction. All receive standalone reviews with three substantial model-specific sections, configuration facts, alternatives and complete-purchase advice. Manufacturer sources were retrieved for all 25 models on October 13. Exact model photos were checked separately; four failing Makita CDN images were replaced with exact-model Acme Tools photographs. Bessey uses the exact KRE3524 retailer photo rather than the manufacturer's ambiguous family illustration.

Eight verified source-rating snapshots and 16 attributed, paraphrased feedback cards were added for eight products. Initials are used for avatars; no reviewer photos, trade credentials, hands-on tests or purchase verification are invented. Favorable and critical experiences remain attributed. No live Amazon price, stock or fixed-ASIN availability is claimed: destinations remain model searches with the existing affiliate routing.

The carpenter hub now has a count-labelled directory button in its hero and a prominent directory band immediately below. Its workflow introduction refers to carpenter work. New specialist choices are linked into relevant existing workflows. The homepage features six editor-selected guides instead of listing every guide, with links to all five trade hubs. Existing routes are preserved.

Local verification: catalogue, feedback and affiliate tests pass; production build passes; lint reports zero errors and eight existing image-optimization warnings. All 25 new photo URLs decode as images. Rendered route audit covers 278 pages, 278 sitemap entries, 7,381 internal links and 318 affiliate destinations. A duplicated Festool description found by the audit was corrected before preview deployment.

Publishing plan: release reviewable batches when useful and checked. Allow a few days for reader review, broken-image monitoring and Search Console observations; do not hold useful pages merely to satisfy an invented Google publishing interval. Avoid thin product variants and spend time improving existing guides. The next 25 should close remaining job gaps after this batch is reviewed. Toolkit configurator follows the catalogue work.

Google guidance: https://developers.google.com/search/docs/fundamentals/creating-helpful-content and https://developers.google.com/search/docs/fundamentals/using-gen-ai-content. Google emphasizes original value for people; large volumes without added value can violate scaled-content policies. There is no weekly publishing rule established by these sources.

This batch is prepared on a review branch. Preview verification and any limitations are recorded separately before production release.
