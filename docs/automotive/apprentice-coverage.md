# Apprentice coverage audit

Checked 15 October 2026 against [Austin Community College’s required tools](https://dmcat.austincc.edu/autotech/required-tools/) and the [Chemeketa Automotive Technology institutional page](https://engineering.chemeketa.edu/programs-classes/program-finder/automotive-technology/). ACC’s page was retrieved. Chemeketa’s institutional page was available as indexed tool-list excerpts; direct retrieval failed. The original librarysearch subdomain was inaccessible. This is a curriculum-informed coverage check, not a claim that the proposed catalogue fulfils either institution’s current enrolment requirements. Students must obtain their current course list.

The audit deliberately leaves visible gaps. It does not include all listed hammers, punches/chisels, a precision steel rule/caliper, every required spark-plug size, full SAE coverage, all required feeler thicknesses, fender protection, battery/ignition accessories or every course-specific item. Some are low-cost consumables/accessories, some are employer-supplied, and some could justify a later substitution after reviewing the exact apprentice workflow. We have **not** silently enlarged the 100 products to claim completeness.

No work-glove candidate is added. No Toolkit Builder application code is changed. Seven reusable records remain single canonical products; automotive associations and missing family mappings are proposed data changes for a later approved implementation.

The 100 products form a trade directory with optional equipment choices, not a shopping list instructing an apprentice to buy all 100. Buying guidance should stage purchases against school/employer requirements, tools already owned and supported vehicles.
